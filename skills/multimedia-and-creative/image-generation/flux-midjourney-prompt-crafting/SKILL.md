# Flux Midjourney Prompt Crafting

## Overview
Diffusion models reward specific cinematography parameters (focal length, lighting, film stock) over generic buzzwords like "photorealistic". Structured prompt syntax ensures reproducible quality.

## Operational Workflow

1. **Define core subject, physical action, and primary environment settings.**:
   - Define core subject, physical action, and primary environment settings.

2. **Specify photographic parameters**:
   - Specify photographic parameters: camera body (Hasselblad, Leica), lens focal length (35mm, 85mm), and aperture (f/1.8).

3. **Define lighting dynamics**:
   - Define lighting dynamics: volumetric rim lighting, golden hour diffusion, or hard neon backlight.

4. **Add technical parameter flags**:
   - Add technical parameter flags: aspect ratio (--ar 16:9), stylization levels, and negative prompt exclusions.
