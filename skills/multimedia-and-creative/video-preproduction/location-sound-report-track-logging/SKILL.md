# Location Sound Report Track Logging

## Overview
Location sound recordists maintain detailed sound reports documenting track channel allocations (boom, lavalier 1, lavalier 2), false takes, room tone tracks, and director preferred takes.

## Operational Workflow

1. **Record project header with sample rate (48kHz/24-bit), frame rate (23.98 FPS), and timecode sync format.**:
   - Record project header with sample rate (48kHz/24-bit), frame rate (23.98 FPS), and timecode sync format.

2. **Log each take row with File Name, Scene, Take, Track Assignments (Ch1 Boom, Ch2 Lav), and Notes.**:
   - Log each take row with File Name, Scene, Take, Track Assignments (Ch1 Boom, Ch2 Lav), and Notes.

3. **Mark director favored takes ("circle takes") and note background noise contamination (e.g., siren during line 3).**:
   - Mark director favored takes ("circle takes") and note background noise contamination (e.g., siren during line 3).

4. **Export PDF sound report and embedded Broadcast Wave Format (BWF) metadata for editorial delivery.**:
   - Export PDF sound report and embedded Broadcast Wave Format (BWF) metadata for editorial delivery.
