# Iso 27001 Isms Audit Checklist

## Overview
ISO 27001 certification mandates comprehensive Annex A security controls (access control, cryptography, physical security). A structured audit checklist tracks implementation status and artifact evidence.

## Operational Workflow

1. **Map Annex A control categories across organizational assets and personnel.**:
   - Map Annex A control categories across organizational assets and personnel.

2. **Assign control ownership, implementation status, and verification frequency.**:
   - Assign control ownership, implementation status, and verification frequency.

3. **Collect documentary evidence**:
   - Collect documentary evidence: policies, change records, and penetration test reports.

4. **Conduct internal pre-assessment gap analysis before external registrar stage 1 audits.**:
   - Conduct internal pre-assessment gap analysis before external registrar stage 1 audits.
