# Vendor Risk Assessment Sig Questionnaire

## Overview
Third-party SaaS vendors represent a massive supply chain risk. Standardized Information Gathering (SIG) evaluates vendor encryption, access control, backup policies, and penetration test cadence.

## Operational Workflow

1. **Issue SIG Lite or SIG Core questionnaire to prospective software vendor security team.**:
   - Issue SIG Lite or SIG Core questionnaire to prospective software vendor security team.

2. **Review submitted SOC 2 reports, ISO certificates, and recent penetration test executive summaries.**:
   - Review submitted SOC 2 reports, ISO certificates, and recent penetration test executive summaries.

3. **Score vendor risk posture across data transmission, hosting infrastructure, and employee vetting.**:
   - Score vendor risk posture across data transmission, hosting infrastructure, and employee vetting.

4. **Issue vendor risk approval or mandate contractually binding security remediation addendums.**:
