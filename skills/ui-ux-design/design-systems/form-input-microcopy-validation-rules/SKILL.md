# Form Input Microcopy Validation Rules

## Overview
Vague error messages ("Invalid entry") cause user frustration. Effective form design uses persistent visible labels, clear helper text explaining constraints, and descriptive inline error messages.

## Operational Workflow

1. **Replace placeholder text with persistent floating or top-aligned <label> elements.**:
   - Replace placeholder text with persistent floating or top-aligned <label> elements.

2. **Add helper text describing formatting requirements (e.g., "Must be at least 8 characters with 1 number").**:
   - Add helper text describing formatting requirements (e.g., "Must be at least 8 characters with 1 number").

3. **Link input to helper and error messages using aria-describedby for screen reader accessibility.**:
   - Link input to helper and error messages using aria-describedby for screen reader accessibility.

4. **Trigger inline validation on blur, providing constructive error microcopy explaining how to fix the input.**:
   - Trigger inline validation on blur, providing constructive error microcopy explaining how to fix the input.
