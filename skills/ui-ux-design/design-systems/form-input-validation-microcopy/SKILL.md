# Form Input Validation Microcopy

## Overview
Generic error messages ("Invalid input") frustrate users and trigger form abandonment. Clear microcopy explains exactly what is wrong and how to fix it in concise, non-accusatory language.

## Operational Workflow

1. **Audit form fields to establish explicit format constraints and validation rules.**:
   - Audit form fields to establish explicit format constraints and validation rules.

2. **Draft inline helper microcopy explaining expectations before user input (e.g. 8+ characters, one number).**:
   - Draft inline helper microcopy explaining expectations before user input (e.g. 8+ characters, one number).

3. **Author concise, empathetic error messages that specify the exact correction needed.**:
   - Author concise, empathetic error messages that specify the exact correction needed.

4. **Connect error text directly to inputs using aria-describedby for assistive technology access.**:
   - Connect error text directly to inputs using aria-describedby for assistive technology access.
