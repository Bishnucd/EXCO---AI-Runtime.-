# Keep A Changelog Curation Standard

## Overview
Dumping raw Git commit logs into changelogs alienates users. Keep a Changelog curates updates for humans, categorizing changes into Added, Changed, Deprecated, Removed, Fixed, and Security.

## Operational Workflow

1. **Maintain [Unreleased] section at top of CHANGELOG.md during active development.**:
   - Maintain [Unreleased] section at top of CHANGELOG.md during active development.

2. **Group bullet points under standardized categories**:
   - Group bullet points under standardized categories: Added, Changed, Deprecated, Removed, Fixed, Security.

3. **Upon release, replace [Unreleased] with version number, release date, and compare link.**:
   - Upon release, replace [Unreleased] with version number, release date, and compare link.

4. **Highlight breaking changes prominently with migration guidance notes.**:
   - Highlight breaking changes prominently with migration guidance notes.
