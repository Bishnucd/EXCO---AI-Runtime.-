# Value Stream Mapping Lead Time Optimization

## Overview
Value Stream Mapping charts the complete lifecycle of a feature from customer request to production release, separating active value-add processing time from wasteful wait states and queue delays.

## Operational Workflow

1. **Map all sequential lifecycle stages**:
   - Map all sequential lifecycle stages: Requirements, Design, Backlog Queue, Dev, QA, Security, Release.

2. **Measure Process Time (actual work done) and Lead Time (calendar time elapsed including waiting).**:
   - Measure Process Time (actual work done) and Lead Time (calendar time elapsed including waiting).

3. **Calculate Flow Efficiency = (Total Process Time / Total Lead Time) * 100.**:
   - Calculate Flow Efficiency = (Total Process Time / Total Lead Time) * 100.

4. **Eliminate the longest non-value-add queue states (e.g., waiting 5 days for manual QA sign-off).**:
   - Eliminate the longest non-value-add queue states (e.g., waiting 5 days for manual QA sign-off).
