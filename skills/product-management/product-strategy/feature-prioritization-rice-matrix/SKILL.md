# Feature Prioritization Rice Matrix

## Overview
Roadmap prioritization easily falls victim to the loudest executive voice. The RICE framework calculates an objective score ($Reach \times Impact \times Confidence / Effort$) to rank initiatives.

## Operational Workflow

1. **Estimate Reach**:
   - Estimate Reach: number of users affected over a specific time window (e.g. users/quarter).

2. **Score Impact**:
   - Score Impact: marginal benefit per user on a discrete scale (3 = massive, 2 = high, 1 = medium, 0.5 = low).

3. **Assign Confidence**:
   - Assign Confidence: percentage reflecting data backing (100% = high data, 80% = medium, 50% = hunch).

4. **Estimate Effort**:
   - Estimate Effort: total person-months required from engineering, design, and product.

5. **Compute RICE Score = $(R \times I \times C) / E$ and sort candidate features.**:
